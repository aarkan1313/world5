## What just shipped (Phase 6 close)

See `docs/build-notes/phase_6_close_2026_05_18.md` for the full
chronology. Key fixes that made the demo finally work:

1. **Re-promoted to 8 siblings per slot** from `D:/tmp/w5_candidates/`
   (texture team's BFL+LOCAL pool). 48 albedo + 48 T_inv + 48 normal +
   48 roughness + 48 AO layers loaded.
2. **W3 M11 sampler stack ported**: `w5_hex_sample_albedo` (proper
   Heitz-Neyret with variance-preserving blend), `w5_variety_sample_plane`
   (region pick + 4-corner crossfade), `w5_variety_sample_triplanar`
   (XY/XZ/YZ blend by world normal — kills stretched-slope wallpaper).
3. **`v_world_normal` varying added** to feed triplanar.
4. **PBR maps wired through the same sampler** (other-chat fix).
5. **Mesh tangents added** to ClipmapGeometry — required for normal
   maps to actually affect lighting.
6. **Mipmaps generated** in SiblingTextureArray; sampler hint set to
   `filter_linear_mipmap_anisotropic`.
7. **Slot/biome accumulator math fixed** (the final visible bug): was
   `biome_slot_rgb[bi] = mix(prev, sib, alpha)` — a successive
   overwrite biased toward last-iteration slot, smearing all slots
   together. Replaced with W3-pattern `acc += sib * w; cov += w` then
   `acc / cov`. Two-stage: per-biome normalize first, cross-biome blend
   by `biome_w` second.
8. **Zero-init accumulators** (was `vec3(0.5, 0.5, 1)` for normal —
   biased the weighted mean).
9. **Per-biome ground-avg fallback color** uniform for coverage gaps
   (replaced single hardcoded olive `vec3(0.35, 0.45, 0.25)`).
10. **macro overlay default neutralized** (`macro_strength_global = 0`).
    Macro stays bound but contributes nothing in production until a
    per-biome macro authoring pass needs it.
11. **All diagnostic toggles stripped** (`macro_debug_mode`,
    `hn_enabled`, keyboard 0-5 handler).

New tool: `pipeline/world5/textures/tx_hn_lut.py` — per-channel
inverse-CDF 256×1 LUT generator. `python -m world5.textures.tx_hn_lut
--world engine/worlds/walking_demo`.

## Known follow-ups (not blocking)

These showed up during Phase 6 work; document so they're tracked:

1. **Source texture polish** — diffusion-generated PBR (FLUX → SM
   tileable) is hit-or-miss vs. photogrammetry. Quality bound by what
   the texture pool delivers, not by the renderer. If demo doesn't
   look AAA, this is the first thing to fix (re-prompt, photogrammetry
   licensing, or Material Anything once its WSL kaolin build works).

2. **Phase 5.4.b.3 detail overlays** still deferred. W3's shader had
   `grass_detail_*` close-range textures soft-light-blended over the
   macro textures < ~30m view distance. Adds high-frequency surface
   character (the "AAA detail" feel). Significant lift when authored.

3. **Per-biome macro authoring** — macro_albedo.json is world-scoped
   today. When biome 3+ lands, refactor to per-biome Texture2DArray
   indexed by biome (mirror the sibling pattern). Macro is currently
   off so no visible impact.

4. **Triplanar region-pick uses world XZ for all 3 planes** — reduces
   variety on cliffsides (X and Z projections pick the same variant).
   Acceptable for v1; revisit if cliffs read poorly.

5. **TerrainWorld loader switch** to catalog-driven kernel + cached
   `bake_page` consumption — eroded terrain is demo-only Python today.
   2-3 session refactor, touches GPU page generation. Worth doing
   before Phase 7 (decoration needs to read the world the player sees).

6. **Spec promotion sweep** never happened. 47 specs still `draft`.
   Lifecycle discipline broken silently — not blocking.
